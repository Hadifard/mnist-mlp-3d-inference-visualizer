# Repository setup checklist

Suggested settings for the GitHub page of this project.

## Repository name

`mnist-mlp-3d-inference-visualizer`

## Description (About box)

```
Interactive 3D visualizer for an MNIST MLP: draw a digit and inspect every neuron, weight and activation in the browser.
```
